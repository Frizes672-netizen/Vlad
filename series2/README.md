# Серия 2 «Он знает моё имя»

Вертикальный ролик 1080×1920, 24 fps, 103,5 с, в плоском мультяшном стиле по референсу (`voice/reference_style.png`).

**Готовый ролик:** `output/series2.mp4` · субтитры отдельным файлом: `output/subtitles.srt`

## Надписи в кадре
- карточка **ДЕНЬ 1** с идущими часами (23:48 → 23:59);
- плашки **ГЛУБИНА** (0 → −52 м) и **ЗОМБИ РЯДОМ** (1 → 40);
- красная плашка **локации**: «Заброшенная хижина», «Под полом», «Старый тоннель», «Подземный бункер № 7», «Лаборатория | Сектор С»;
- **бейджи** над персонажами: ВЛАД (ничего не помнит → объект № 17 → создатель), ВИКА (что-то скрывает → держит на мушке → в шоке), СПАСАТЕЛЬ, УЧЁНЫЙ;
- надписи по сценарию: табличка бункера, «ОБЪЕКТ № 17» под фото, экран компьютера, финальная «ПРОДОЛЖЕНИЕ СЛЕДУЕТ…».

Крупные пословные субтитры, как на референсе, выключены; включаются через `CAPTIONS = True` в `timeline.py`.

## Озвучка
`voice/voiceover.mp3`, вступает на 0,3 с. Монтаж выровнен по фразам озвучки; пословная разметка лежит в `voice/words.tsv`.

## Пересборка
```bash
./build.sh
```
| Файл | Что делает |
|---|---|
| `timeline.py` | события `EV`, локации, глубина, счётчик зомби, часы |
| `render.py` | персонажи, локации, камера, HUD-плашки, бейджи |
| `audio.py` | звуки: удары в дверь, люк, эхо тоннеля, стальная дверь, компьютер, сирена, толпа зомби |
