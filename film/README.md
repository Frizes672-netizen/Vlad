# «Ночь только начинается…» — хоррор-шорт

Вертикальный ролик 1080×1920, 24 fps, 88 с (озвучка + финальная надпись).
Картинки, анимация, звуковой дизайн и надписи генерируются кодом (Python + numpy + Pillow + ffmpeg).

**Готовый ролик:** `output/night_begins.mp4` · субтитры: `output/subtitles.srt`

## Озвучка

Голос: `voice/voiceover.mp3` (ElevenLabs). Он вступает на 1,5 с, после открытия глаз; сдвиг задан в `VOICE_OFFSET` в `timeline.py`.
Монтаж, звуки и субтитры выровнены по фразам озвучки: их тайминги получены распознаванием речи по словам.
Под голосом звуковые эффекты автоматически приглушаются (sidechain).
Чтобы заменить озвучку, положите новый файл в `voice/voiceover.mp3`, поправьте `EV` и `SUBS` в `timeline.py` и запустите `./build.sh`.

## Пересборка

```bash
./build.sh
```

| Файл | Что делает |
|---|---|
| `timeline.py` | формат кадра, ключевые события `EV`, субтитры, заголовки глав |
| `render.py` | все сцены, анимация, камера, тряска, вспышки, плёночное зерно, надписи |
| `audio.py` | звуки: волны, огонь, рык, бег, хруст, дверь, скрежет, стуки, сердцебиение, рация, стингеры |
| `make_srt.py` | экспорт субтитров в SRT |
