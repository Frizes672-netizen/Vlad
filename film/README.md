# «Ночь только начинается…» — хоррор-шорт

Вертикальный ролик 1080×1920, 24 fps, 84 с (80 с по сценарию + финальная надпись).
Картинки, анимация, звуковой дизайн и надписи генерируются кодом (Python + numpy + Pillow + ffmpeg).

**Готовый ролик:** `output/night_begins.mp4` · субтитры: `output/subtitles.srt`

## Наложить свою озвучку

```bash
./mix_voiceover.sh путь/к/озвучке.mp3        # озвучка начинается с 0:00
./mix_voiceover.sh путь/к/озвучке.mp3 1.5    # сдвинуть голос на 1,5 с
```
Результат: `output/night_begins_voice.mp4`. Звуковые эффекты автоматически приглушаются, когда звучит голос.
Если реплики не совпадают с надписями, поправьте тайминги в `timeline.py` (список `SUBS`) и пересоберите ролик.

## Пересборка

```bash
./build.sh
```

| Файл | Что делает |
|---|---|
| `timeline.py` | формат кадра, субтитры, заголовки глав |
| `render.py` | все сцены, анимация, камера, тряска, вспышки, плёночное зерно, надписи |
| `audio.py` | звуки: волны, огонь, рык, бег, хруст, дверь, скрежет, стуки, сердцебиение, рация, стингеры |
| `make_srt.py` | экспорт субтитров в SRT |
